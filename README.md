# Aaaah! - Editeur de cartes

Editeur visuel de cartes pour le jeu **Aaaah!** sur [Extinction-MiniJeux](https://extinction-minijeux.fr).

Application web autonome (HTML/CSS/JS, fichier unique, sans framework ni dépendance).

## Utilisation

Ouvrir `index.html` dans un navigateur. Aucune installation requise.

## Fonctionnalites

- **Formes** : lignes, courbes (Bezier), rectangles, ellipses, polygones
- **Elements speciaux** : cristaux (CRI), teleporteurs (TP)
- **Groupes** : regrouper des formes pour les deplacer ensemble
- **Animations** : translation et rotation avec boucle/aller-retour
- **Import/Export XML** : format compatible avec le jeu
- **Sprites** : rendu avec les vrais sprites du jeu (passerelle, infirmerie, bloc droit, etc.)
- **Calque modele** : superposer une image de reference pour tracer par-dessus
- **Grille et aimantation** : alignement sur grille ou sur les formes existantes
- **Copier-coller, duplication, miroir H/V**

## Raccourcis clavier

| Raccourci | Action |
|---|---|
| V | Outil selection |
| L | Outil ligne |
| C | Outil courbe |
| R | Outil rectangle |
| E | Outil ellipse |
| P | Outil polygone |
| K | Outil cristal (CRI) |
| T | Outil teleporteur (TP) |
| Ctrl+C / Ctrl+V | Copier / Coller |
| Ctrl+D | Dupliquer |
| Ctrl+G | Grouper la selection |
| Ctrl+Z / Ctrl+Y | Annuler / Refaire |
| Suppr | Supprimer |
| Shift+glisser | Contraindre lignes (H/V/45) |
| Clic droit + glisser | Deplacer la vue |
| Molette | Zoom |
