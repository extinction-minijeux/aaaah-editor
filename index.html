Groupes ?Grouper : sélectionnez plusieurs formes (Ctrl+clic ou rectangle de sélection) puis Ctrl+G ou le bouton. Les formes groupées se déplacent ensemble.
Dégrouper : retire uniquement la forme sélectionnée du groupe. Si le groupe tombe à 1 forme, il est dissous.
Tout grouper : regroupe toutes les formes de la carte.
Dans le XML, les groupes sont des balises <G>.

Grille ?Grille de repère visuel purement cosmétique. N'affecte pas le placement des formes. Indépendante de l'aimantation.

Aimantation ?Grille : aligne les positions sur un pas régulier (indépendant de la grille visuelle).
Pas : intervalle en pixels (ex: 5 = toutes les 5px).
Formes : aligne sur les points des formes existantes (sommets, centres, extrémités). Des guides verts apparaissent quand un alignement est détecté.
Tolérance : distance en pixels pour la détection d'un point proche.

Calque modèle ?Chargez une image (screenshot du jeu, croquis, dessin) comme modèle de fond pour tracer vos formes par-dessus. L'image est purement visuelle et n'est pas exportée dans le XML. Ajustez l'opacité, la position et la taille pour l'adapter à la carte.

?Sélection (V) : clic = sélectionner, Ctrl/Cmd+clic = multi-sélection, rectangle de sélection = clic+glisser sur le vide. Point central rouge pour déplacer un groupe. Tirer les handles (carrés rouges) pour modifier les points d'une forme.
Ligne (L) : cliquer-glisser. Shift = ligne droite (H/V/45°).
Courbe (C) : cliquer-glisser, puis ajuster le point de contrôle bleu.
Rect (R) / Ellipse (E) : cliquer-glisser. Shift = proportions contraintes.
Polygone (P) : cliquer pour chaque sommet, double-clic ou clic sur le premier point pour fermer.
Cri (K) : cliquer pour placer un cristal. Inversé modifiable dans les propriétés.
TP (T) : cliquer pour placer, tirer le sprite destination pour la déplacer.
Forme remplie : si coché, les rect/ellipse/polygones créés seront pleins.
Épaisseur : valeur par défaut pour les nouvelles formes (min 1).

Raccourcis clavier :
Ctrl+C/V : copier-coller
Ctrl+G : grouper la sélection
Ctrl+Z/Y : annuler/refaire
Ctrl+D : dupliquer
Suppr : supprimer
Shift+glisser : lignes droites

Propriétés ?Propriétés de la forme sélectionnée.
Position X/Y : coordonnées sur la carte.
Largeur/Hauteur : dimensions (lignes/courbes = dx/dy relatifs).
Angle X/Y : point de contrôle des courbes.
Épaisseur : taille du trait (min 1).
Rempli : plein ou contour (rect, ellipse, polygone).
Cri : inversé = retourne le cristal.
TP : Dest. X/Y = coordonnées de destination du téléporteur.
Tirez les handles (carrés rouges) sur le canvas pour modifier visuellement.

Translation ?Anime la forme en la déplaçant vers une cible. Non disponible pour les Cri et Téléporteurs.
Placer : cliquez sur le canvas pour définir visuellement la destination. Vous pouvez aussi tirer le handle bleu (cercle avec flèche).
Départ : délai avant le début du mouvement (secondes).
Durée : temps du trajet (secondes).
Cible X/Y : coordonnées de destination (éditables manuellement).
Boucle : Aucune (une seule fois), Boucle (répète), Aller-retour.

Rotation ?Anime la forme en la faisant tourner sur elle-même. Non disponible pour les Cri et Téléporteurs.

Durée : temps pour compléter la rotation (secondes).
Degrés : angle total de rotation (360 = tour complet).
